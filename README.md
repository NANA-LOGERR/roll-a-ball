Esse jogo (Prototipo) é um game onde você é uma bolinha onde você (Jogador) tem que coletar losangos(Pontos) enquanto foge da bolinha inimiga, 
a quantidade de pontos são 20 terá losangos verdes que retribui a um ponto é os losangos roxos que retribui a três pontos.
O objetivo do jogo é ter que coletar os 20 pontos enquanto foge da bolinha que te persegue.
