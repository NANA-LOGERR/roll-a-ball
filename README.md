**Aluno:** João Victor Ribeiro de Lima Souza

**Feito com:** Unity 6 e C# 
## Sobre o projeto
Você controla uma bolinha onde tem que pegar lozangos verde é roxos para pontuar enquanto foge de uma bolinha inimiga.

## O que o projeto faz
O jogador controla a bolinha com o WASD é pega os lozangos é eles desaparecem. 

**Scripts:** 
CameraController, EnemyController, PlayerController, Rotator. 

**Objetos principais:** 
Walls, Pick Up, Canvas, Enemy, player. 

**Recursos usados:**
TextMeshPRO, BoxCollider, MeshCollider, RigyBody, SphareCollider. 

## Controles
W- vai pra frente
S - Vai para trás 
A- Vai para a direita 
D - Vai para a esquerda
